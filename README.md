# 🧩 Web Editor de Arquivos CSV/Excel com Streamlit

Este projeto é um app web interativo feito em Python com **Streamlit**, que permite aos usuários:

✅ Enviar arquivos CSV ou Excel  
✅ Visualizar e editar os dados em tempo real  
✅ Adicionar ou remover linhas e colunas  
✅ Baixar o arquivo modificado no formato CSV
